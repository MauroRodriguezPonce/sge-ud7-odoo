## Resumen del proyecto
 
1. **Instalación:** Odoo Community en Docker, con base de datos propia y sin datos de demostración.
2. **Empresa:** configuración de la compañía, diseño de documentos corporativo, catálogo de 4 productos y 2 clientes.
3. **Usuarios y permisos:** 3 usuarios internos con mínimo privilegio, un usuario portal y un grupo propio con herencia y derechos de acceso.
4. **Venta completa:** presupuesto → pedido → entrega → factura → pago, cada paso con el usuario de su rol.
