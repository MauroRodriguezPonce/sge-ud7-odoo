# Errores de instalación

| Error o mensaje | Causa | Solución aplicada | Fuente consultada |
|---|---|---|---|
| `Docker Desktop failed to start because virtualisation support wasn't detected` | La virtualización estaba desactivada en la BIOS/UEFI y Docker Desktop la necesita para funcionar. | Reinicié el equipo, entré en la BIOS/UEFI, activé la virtualización, guardé los cambios y volví a abrir Docker Desktop. | Consulte en la documentación de Docker Desktop y a Claude |
